| Phrase | Intended route |
| --- | --- |
| Make a responsive landing page in FormWeb | Harness director |
| Fix the FormWeb mobile breakpoint layout | Layout builder |
| Add reusable components to my FormWeb portfolio | Layout builder |
| Build a blog CMS site in the Form family editor | Harness director |
| Update CMS collection records in FormWeb | CMS steward |
| Add Spanish localization to the FormWeb page copy | Localization |
| Make this bigger (with an element selected in the FormWeb editor) | Agent Connect and terminal, layout builder |
| Password-protect the members page of my FormWeb site | Site and pages |
| Create 40 product pages in FormWeb from this CSV | Site and pages |
| Change the brand color token and type scale in FormWeb | Style and tokens |
| Turn the FormWeb pricing card into a component with a featured variant | Components |
| Fix the missing alt text and page descriptions in FormWeb | SEO and accessibility auditor |
| Export the FormWeb contact form submissions as CSV | Forms operator |
| Approve the agent's pending FormWeb release for review | Branch and review, Agent Connect and terminal |
| Which port and file does FormWeb's MCP use | Platform map |
| Add click interactions and a contact form in FormWeb | Interaction builder |
| Audit the FormWeb site accessibility and SEO | Recovery auditor |
| Save the editable .fweb project and export HTML CSS JS | Release operator |
| Publish the FormWeb site as a local preview | Release operator |
| Give this FormWeb component typed props, variants and two slots | Layout builder |
| Build CMS detail pages and locale alternates in my FormWeb site | CMS steward, localization |
| Review the FormWeb branch conflicts and keep the approved content | Branch and review, recovery auditor |
| Connect the FormWeb form inbox to configured signed delivery | Forms operator |
| Inspect the configured FormWeb commerce and analytics providers | Release operator, interaction builder |

The description auditor checks keyword coverage of these positives. Model selection remains a separate manual check; lexical overlap is not proof of runtime activation.

## Should not trigger

| Near miss | Correct boundary |
| --- | --- |
| Fix a TypeScript error in the FormWeb frontend source | Repository development: the `formweb-editing` skill |
| Add a new engine command to FormWeb's Rust crate | Repository development: the `formweb-editing` skill |
| Change how the FormWeb terminal WebSocket authenticates | Repository development: the `formweb-editing` skill |
| Create a FastAPI endpoint for FormWeb authentication | Backend implementation work |
| Benchmark Rust memory usage in the FormWeb engine | Engine development and profiling |
| Log into my Framer account and edit its CMS blog | Framer account tools, when authorized and available |
| Transfer a Webflow custom domain to another account | Webflow account administration |
| Compare Framer and Webflow subscription prices | Current-source research |
| Draw a vector logo for the FormWeb website in FormPath | FormPath illustration harness |
| Translate this paragraph into Spanish without editing a site | Direct translation |
| Analyze a CSV export of contact-form submissions | Spreadsheet or data analysis workflow |
| Review this static HTML code for a security bug | Source-code review |

These negatives intentionally share terms with the positives. The boundary should prevent the runtime-site workflow from replacing source development, current factual research, adjacent editors or account administration.

## Read-back check

Ask an independent evaluator when it would use the master description, then compare its paraphrase against both tables. It should identify editing an actual FormWeb site through connected tools, include save/export and local preview outcomes, and exclude repository implementation or unrelated service accounts. Record the observed result outside the pack; do not label this specification as a completed activation test.
