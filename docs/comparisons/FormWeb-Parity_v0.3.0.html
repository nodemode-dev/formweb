How to read the audit

Targets are engineering decisions derived from the researched workflows. FormWeb grades come from the actual command, SDK, editor, compiled browser and service observations retained with this release. A command or value stored in the model cannot earn full credit unless the user workflow and consuming output exist. Protocol fixtures establish their declared transport and runtime scope; live vendor deployment, domain/TLS/CDN and payment completion require independent operational proof.

Webflow User Accounts sunset supersedes older pages that still mention that feature. Framer Server API, local agents and custom MCP construction are distinct surfaces. Webflow static site export and DevLink React component export are also distinct.

Adobe Express and Canva were researched on 2026-10-11 from fetched official Adobe and Canva pages only. Adobe Express webpages are single, section-based pages; HTML export is documented only in a beta generation article. Canva Websites documents pages, responsive layout, domains, forms, SEO, sitemap and insights, while its Connect API has no website design type and its MCP server requires a waitlist. Rows FW-066 to FW-079 come from documented Express or Canva web features and are FormWeb integration targets, several of them sourced from the Form family: formvis for image cleanup and formlit as a local photo library.
