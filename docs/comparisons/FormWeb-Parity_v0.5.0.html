        Sources and method

        FormWeb. Each grade comes from executed commands, SDK and MCP calls, editor flows and compiled browser output retained with the release; a stored value without a consuming workflow does not earn Full.

        Vendors. Each cell rests on the cited official page. Unknown is not absence: a None marked Not found means only that the sources read did not show it.

        Scoring. Full counts 1, Partial one half, None 0, over all rows. Documented counts as Full and Integration as Partial for the vendors.

        Tracking. Per-row grades for every release are kept in docs/comparisons/data/formweb-parity.json; ./formweb comparisons build renders this page and the change tables from them, and ./formweb comparisons embed puts it in the FormAI matrix.
