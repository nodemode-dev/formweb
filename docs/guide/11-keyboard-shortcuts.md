# Keyboard shortcuts

These tables were generated from the app's own list of commands, read from the running app (`window.formweb.commands()` in FormWeb 0.28.0), not written from memory. Every command in that list that has a shortcut is here.

On Windows and Linux the shortcuts use Ctrl; on a Mac they use Cmd, and Alt is Option.

To find any command by name, with its shortcut, press Ctrl+K (Cmd+K on a Mac) and start typing.

## Keys inside lists, menus and fields

These keys belong to the Pages and Layers lists, menus and text fields rather than to a command, so they are not in the command list above. Each was tried while writing this guide.

| Key | Where | What it does |
| --- | --- | --- |
| F2 | A page or layer row | Rename it in place |
| Enter / Escape | Renaming, or a field in the right panel | Keep the change / keep the old value |
| Shift+F10 | A page or layer row | Open its right-click menu |
| Alt+Up, Alt+Down | A page or layer row | Move it up or down one place |
| Left, Right | A layer row | Fold or unfold its children |
| Ctrl+click, Shift+click (Cmd+click on a Mac) | Rows, or elements on the canvas | Add to the selection, or select a range of rows |
| Escape | Several rows selected | Go back to one |
| Escape | While dragging | Cancel the drag |
| Up, Down, Enter | Quick insert, Search properties | Move through the list and choose |
| Escape | Preview as published | Close it |
