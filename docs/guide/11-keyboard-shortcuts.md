# Keyboard shortcuts

These tables were generated from the app's own list of commands, read from the running app (`window.formweb.commands()` in FormWeb 0.31.1), not written from memory. Every command in that list that has a shortcut is here.

On Windows and Linux the shortcuts use Ctrl; on a Mac they use Cmd, and Alt is Option.

To find any command by name, with its shortcut, press Ctrl+K (Cmd+K on a Mac) and start typing.

## Keys inside lists, menus and fields

These keys belong to the Pages and Layers lists, menus and text fields rather than to a command, so they are not in the command list above. Each was tried while writing this guide.

| Key | Where | What it does |
| --- | --- | --- |
| F2 | A page or layer row | Rename it in place |
| Enter / Escape | Renaming, or a field in the right panel | Keep the change / keep the old value |
| Shift+F10 | A page or layer row | Open its right-click menu |
| Alt+Up, Alt+Down | A page or layer row | Move it up or down one place |
| Left, Right | A layer row | Fold or unfold its children |
| Ctrl+click, Shift+click (Cmd+click on a Mac, where Ctrl+click is a right-click) | Rows, or elements on the canvas | Add to the selection, or select a range of rows |
| Escape | Several rows selected | Go back to one |
| Escape | While dragging | Cancel the drag |
| Escape | Select several is on | Turn it off and keep the selection |
| Up, Down, Enter | Quick insert | Move through the list and choose |
| Escape | Search properties | Clear the search; in an empty search field, move to the tab buttons. The list of results cannot be moved through or picked from: it only shows where each setting is |
| Escape | Preview as published | Close it |
| Left, Right (or Up, Down), Home, End | A choice button in the Design tab, such as Center in Text alignment | Try the next or previous choice, or the first or last, on the page without saving it |
| Space, Enter, Up, Down, Alt+Down | A Design field that is a list, such as Weight or Object fit | Open the list without trying anything |
| Up, Down, Home, End, a letter | The open list of a Design field | Try that item on the page; the list stays open |
| Enter / Escape | A choice being tried: on the choice, in the list, or on the Keep and Revert bar | Keep it (one undo step) / put the page back |
| Tab | A choice being tried | Go to Keep, then Revert; Tab from Revert moves on and puts the page back |
| Ctrl+Z (Cmd+Z on a Mac) | While a choice is being tried | Put the page back; nothing earlier is undone |
| Left, Right (or Up, Down), Home, End | A slider under a Design field | One step, or the lowest or highest value; Shift with an arrow moves ten steps. A key held down is one undo step |
| Up, Down | The text box of a Design field with a slider, holding one number such as `12px` | Step by one slider step and keep the unit (`12px` to `13px`, `1rem` to `1.25rem`, `0.5` to `0.51` for Opacity); with Shift, ten steps. Not while the field is switched to CSS text |
| Escape | While dragging a slider, or in the color picker during a drag | Put the old value back |
| Enter, Space | A color swatch, or the layout button of Grid columns or Grid rows | Open the color picker or the layout chooser |
| Arrow keys, Home, End | The color picker's square, hue and opacity bars | Change the color step by step; Shift for bigger steps |
| Arrow keys, Enter, Space | The layout chooser of Grid columns or Grid rows | Move between the layouts and choose one |
| Arrow keys, Home, End, Delete | A stop handle on the Gradient tab | Move the stop (Shift for 10 %), send it to an end, remove it |
| Escape | The color picker or the layout chooser | Close it and go back to its button |
| Ctrl+Z, Ctrl+Shift+Z (Cmd on a Mac) | A slider, a swatch, a gradient stop, a button of a control (such as the layout button or the `</>` switch), the color picker's square and bars, a layout in the chooser, or a Design field that is a list, such as Weight | Undo and Redo, as anywhere else. In a text box they undo typing in that box; from a unit list, press Tab or click elsewhere first |
| Delete, Backspace | Any part of a control, as above, a choice button such as a Display choice, a Design list and its open list, the Keep and Revert bar, the Design, Motion, Content and Page tabs, a section title such as Layout, a button in the toolbar (such as Audit, Export or a breakpoint button), an audit marker, or the Convert to editable elements window while it works | Nothing happens to the selected element (on a gradient stop, the stop is removed) |
| Enter, Space | An audit marker on the canvas | Select its element and show its issues |
