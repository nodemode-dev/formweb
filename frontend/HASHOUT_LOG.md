## Variable width on closed shapes · v0.12.7 (2026-10-17)

## Vector PDF export · v0.12.4 (2026-10-17)

New `vector/pdfexport.ts` (`svgToPdf`): a dependency-free PDF 1.7 writer. It walks the rendered svg in the canvas iframe (so computed styles apply), composes each element's `transform` by hand, and writes paths (path, rect, circle, ellipse, line, polyline, polygon) with fill and stroke colour, width scaled by the transform, cap, join, miter, dash and fill rule; opacity, fill-opacity and stroke-opacity through ExtGState; clip-path groups as PDF clipping paths; `use` instances by walking their symbol; text lines (the direct tspans, each with x and y) in Helvetica, one of the PDF base fonts, at their size, colour and anchor (anchor shift from `getComputedTextLength`). Gradients fall back to their first stop colour; patterns, images, masks, filters and blend modes are skipped. One drawing unit is one point; the page is the export's viewBox (whole drawing or selection crop). `vector/exportscreens.ts`: format `pdf` (written once, like SVG, whatever scales are ticked), `Source` carries the live svg, its viewBox and the chosen ids. `commands/catalogue.ts` export entry; `docs/AGENT_QUICKSTART.md` lists PDF and the v0.12.2 and v0.12.3 commands.

- **Source basis:** Figma Help "Export formats and settings": PDFs include text, fonts, vector graphics and images in a fixed layout, text as glyphs, 1x only, PDF 1.7, Plus darker and Plus lighter blend modes not supported. Bleed and crop marks are not documented there, and none are written here.
- **Found while driving:** the canvas renders each text line as a tspan holding an inner tspan, so the first version drew every line twice (once at 0,0); only direct tspan children are drawn now. A first test drew shapes outside the drawing's box, which the export (like PNG and SVG) crops away; the test was redrawn inside a backdrop.
- **Driven (CPU 4x, 400 ms latency, slow network, cache off):** a stroked backdrop rectangle, a rectangle and ellipse made into a mask with Use as mask, and area type in a further ellipse; Export for Screens with PNG and PDF ticked downloaded pdf-check.png and pdf-check.pdf. qpdf --check: no syntax or stream errors; pdfinfo: 1 page, 618.59 by 666.96 pt, PDF 1.7; pypdf text: "Vector PDF / export keeps paths, clips and text / from the drawing."; the page rendered with Poppler matched the PNG export side by side (clipped arc, outlines, text placement). No page errors.

## Rectangle tool freeze · v0.8.9 (2026-10-16)

Edit in `vector/editor.ts` (`down`), one line added.

- **Root cause:** `down` returned early while a commit was in flight (`busy`) before it reached `event.preventDefault()`. A press on the overlay capture rect during that window was therefore not cancelled: the browser fired `mousedown` and started native selection or drag handling (`selectstart`, and `dragstart` when text was selected) on the overlay. The following pointer moves then ran against a native drag session that no script was driving, so the page was idle (not at 100 percent CPU) while Playwright's `mouse.move` never returned. A second press right after drawing the first shape lands inside that busy window, which is why it needed one shape just drawn and selected. Escape or a Selection tool click first avoids it only because the second press then no longer reaches this path in time. There is no loop in snapping, geometry or the overlay.
- **Fix:** `down` now cancels the press for the active tool (`tool !== null`, primary button) before the busy and gesture guards, so a press during a commit is swallowed without starting native selection or drag. Confirmed with event logging: before, the second press produced `mousedown` and `selectstart` or `dragstart` on `.fw-vo-capture`; after, only `pointerdown`.
- **Limit:** a hang with no pending commit was not reproduced in 100+ drags, so this is the one confirmed path to a native drag from the Rectangle tool.
- **Driven (real engine, latency 600 ms):** Rectangle, Ellipse, Polygon, Star and Pen each drew a first shape, a second away from it pressed immediately, and one overlapping it; every drag completed, page script evaluation stayed responsive, and `GET /api/state` path count rose by one each time.

## Vector editing · v0.6.0 (2026-10-16)

`vector/` (new), `styles/vector.css`, small edits in `ui/canvas.ts`; model, export and backend allowlists in the same change.
- **Element model:** an inline vector is an `svg` node (viewBox, width, height; styles position absolute, left, top, overflow visible) holding `path` nodes. Each path has `d` plus `data-fw-vector`, a JSON anchor model `{"v":1,"subs":[{"closed","nodes":[{x,y,in,out,kind,corner}]}]}`. `d` is always the rendered result, so Live Corners are non-destructive: the model keeps the sharp anchors and a per-anchor `corner {type round|inverted|chamfer, radius, mode absolute|relative}`. - **Geometry:** `geometry.ts` (anchors, d parse and format, split, kind conversion, shape generators, model encode and decode), `corners.ts` (tangent distance d = r / tan(theta / 2), clamped per segment by arc length and by neighbouring corners; cubic arc with k = 4/3 tan(phi / 4); inverted reflects the arc across the chord; chamfer is a line; curved neighbours are split at arc length d and use their own tangents), `edit.ts` (delete, add, scissors, join, average, simplify, offset, outline stroke with caps, joins and dashes), `fit.ts` (curve fitting, from formdeck), `boolean.ts` (flatten, arrange, link loops, from formdeck; the nine Pathfinder operations).

## src/api.ts

### src/api.ts · authoritative state and concurrency

- refers-to: `src/api.ts` :: command, commands, replace, connect
- kind: rationale
- logged: v0.1.0 · 2026-10-10

The frontend has no second document engine. It renders Rust state returned through FastAPI. Mutations and document replacements are serialized; command mutations include `expectedRevision`. Single commands, including undo and redo, use `/api/command`; atomic multi-node insertions use `/api/batch`. Save, audit, publish and downloads wait for pending edits before taking their snapshot. SSE forwards agent modifications into the same mounted view. Revision conflicts fetch current state, retain a focused input and show an explicit retry message.

### src/api.ts · token and asset transport

- refers-to: `src/api.ts` :: authHeaders, connect, download, upload
- kind: rationale
- logged: v0.1.0 · 2026-10-10

Optional server tokens live in sessionStorage, become Bearer headers and establish a local HttpOnly session cookie through `/api/auth` for EventSource. Tokens are not placed in URLs. Raw image intake accepts PNG, JPEG, WebP and GIF up to 8 MiB; the backend validates and stores bytes. Editable downloads use `/api/project-file`, while static export uses `/api/export`.

## src/ui/canvas.ts

### src/ui/canvas.ts · persistent iframe and keyed document

- refers-to: `src/ui/canvas.ts` :: constructor, render, patch
- kind: rationale
- logged: v0.1.0 · 2026-10-10

The iframe is initialized with `srcdoc` once. It permits same-origin access but no scripts, and its CSP rejects script and form execution. Subsequent state changes update cached nodes, individual attributes/styles and text spans. No live body innerHTML or srcdoc rebuild occurs. A tag change replaces only that one element, transferring its already mounted children. Inactive page roots are kept mounted and hidden. Canvas viewport space is reserved before the engine responds, and fitting changes one frame transform.

### src/ui/canvas.ts · responsive, locale and CMS parity

- refers-to: `src/ui/canvas.ts` :: patch
- kind: rationale
- logged: v0.1.0 · 2026-10-10

Base styles merge maxWidth 100000 desktop overrides, then matching narrower breakpoint overrides in descending order. Text uses node-ID locale keys. Published collection lists repeat keyed instances and descendant fields use the current item. Draft items are omitted. Image fields bind src. Repeated DOM identities include collection and item IDs, while selection resolves to the original engine node. Nested collections compose suffixes and inherit a subtree HTML-ID map: matching id, for, ARIA references, fragment hrefs and interaction URLs stay in the correct item, while references outside the repeated scope remain unchanged. Fragment navigation resolves inside the iframe. Allowed HTML tags and attributes match the Rust model, excluding active form action/method in the editor sandbox. Image changes decode offscreen before swapping the source, with a latest-source guard and cache reset on removal.
