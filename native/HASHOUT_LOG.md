# Native engine decisions

## Per-site hidden scrollbars · v0.3.1

`formweb-export` `stylesheet()` appends `*{scrollbar-width:none}*::-webkit-scrollbar{display:none;width:0;height:0}` when `site.settings.hideScrollbars` is the string "true". Settings already travel through `site.update` and `merge_strings`, so no engine command changed; `route_styles::base` clones the site with settings intact, so Preview, export and publish all honor it. Off by default; existing projects export byte-identical CSS.

## Authority and dependency boundary

Rust owns the document, command history, validation and deterministic exports. Python owns process supervision, persistence, ZIP packaging, local publication and MCP. Both UI and agents operate on the same core. Four crates keep the process shell thin and the model independent. Direct dependencies are serde, serde_json, getrandom and sha2, with exact resolved versions and transitive dependencies retained in Cargo.lock. getrandom 0.4.3 supplies cross-platform OS entropy and is MIT OR Apache-2.0 ([official documentation](https://docs.rs/getrandom/0.4.3/getrandom/)). sha2 0.11.0 verifies actual source and compiled code digests and is MIT OR Apache-2.0 ([official crate documentation](https://docs.rs/sha2/0.11.0/sha2/)). Workspace code uses Apache-2.0.

## Transaction and failure semantics

Commands apply to a cloned candidate, followed by whole-document validation. The candidate is committed once after all batch commands succeed. Undo/redo remain outside batches. History is bounded to 100 entries. No-ops preserve revision and redo. Failed validation cannot leave a changed document or partial history. The final page cannot be removed. Component source nodes cannot be deleted while referenced.

## Safe stored content

Semantic tags and attributes are allowlisted. URL schemes, bounded CSS property names and unsafe CSS forms are checked before state enters the authority. The export escapes user content and serializes interaction records as JSON with script-sensitive characters escaped. Image bindings require typed image/URL fields. CMS date validation checks real calendar ranges, including leap years. These guards do not substitute for a complete browser conformance or accessibility audit.

## Component identity and overrides

Linked instances carry explicit source IDs and override field groups. Source updates propagate to unoverridden field groups; instance-local text and appearance remain independent after an override. Stored instance trees and inherited fields are validated against their source. HTML IDs are remapped to stable instance-specific IDs. Labels, ARIA references and local fragments reuse the same map, preventing cloned forms from targeting source controls. The v0.2 authority synchronizes source structure while preserving surviving clone IDs, and consumes typed props, variants, slots, category resets and detach. Nested linked source definitions require explicit detach before defining the outer source.

## Portable output

Known page links, including navigation interaction URLs, resolve relative to each exported directory depth. This prevents links from escaping a local publication prefix. Metadata still uses the selected public base URL. The baseline exporter selects one locale; the advanced compiler emits configured locale and CMS routes. Missing strings fall back. CMS list expansion excludes unpublished items and has a rendered-node budget. Repeated subtrees carry an explicit HTML ID map: IDs, label targets, ARIA references, local fragments and interaction fragment destinations resolve within the same item. References to targets outside the repeated subtree stay unchanged. Nested repeats compose identity suffixes. Remote assets remain remote references.

## Forms and recovery

Every engine startup and new website receives a fresh 128-bit OS-random site identity, preventing independent sites from sharing a submission namespace. Entropy failure aborts startup or the new command without a predictable fallback. Load and supervised recovery preserve the stored identity. The runtime submits URLSearchParams text fields for default FormWeb forms, matching the backend's supported URL-encoded intake. File values are explicitly rejected. Explicit custom form actions and methods remain authored and use native browser submission. Status space is reserved in exported markup. Protocol-only restoreRevision lets the supervisor restore its last acknowledged revision after a core restart. Legacy load clears history; complete checkpoint restore validates and preserves both undo and redo arrays before mutation.

Named surgical edits extended Site with a defaulted bounded extensions map and Field with an optional relation collection. New handwritten model and engine advanced modules validate and consume the extension namespaces, while the JSON-lines shell gained validate/checkpoint/restore. The existing mutation dispatcher gained structural synchronization and linked full-page duplication. Persistent checkpoints retain both history directions, reject cross-site history and validate every stored document before authority changes. The full serialized site has an 8 MiB cap, extensions a 4 MiB cap, restored checkpoints a 32 MiB cap, and ordinary history a 31 MiB trimming budget.

Typed token definitions store actual CSS values and type metadata together. Applied text presets retain node associations and per-property overrides, including removal of obsolete preset properties. Component source add/remove changes synchronize into linked trees; typed props and variants materialize, reset categories preserve unrelated instance data, slot replacement and full reset release supplied content safely, and detach keeps the materialized content. Library pins namespace tokens and breakpoints, preserve source node provenance on explicit version updates, retain instance overrides and reject local source/definition/design conflicts. Unsupported selected-source dependency classes reject with a clear message rather than being silently dropped.

CMS predicates are checked against resolved field types, including scalar versus multiple-reference results. Localized merged values, slugs/statuses and actual relation targets are validated. URL bindings require singular typed URL/image fields. Behavior commands require the relevant valid target/variant/timeline/overlay arguments; authored analytics goals must match configured experiments. Form constraints reference enabled descendant fields and ordered bounds; generated tracking fields cannot shadow ordinary visible controls. Code groups require explicit opt-in, bounded source/compiled output, SHA-256 matches and typed instance props. Provider groups contain public descriptors and bounded HTTPS/loopback endpoints only.

## Advanced compiler decisions and owner observations

The compiler consumes the defaulted extension namespaces for scoped CMS queries, bindings, relations and detail pages; locale routes, metadata and hreflang; per-route CSS and configuration; and asset ownership manifests. Static export rejects membership gates. Private member output omits the native document and relies on server authorization of immutable routes and assets. Authored code runs only after explicit opt-in and compilation in an opaque sandbox. Runtime variant switches restore the source baseline and apply variants plus typed props, preserving mounted DOM and resolving source HTML fragments through instance identity maps. Timeline keyframes normalize hyphenated CSS names for WAAPI; reduced motion applies final CSS values.

The compiler owner's retained research evidence is part of the planning sidecar. `compiler-final-native-observations-v020.json` records seven English/French routes and 24 files, withheld localized-draft src/href bindings, page asset ownership and typed 302 redirect passthrough. `compiler-browser-observations-v020.json` and `compiler-final-browser-observations-v020.json` record security-enabled Chromium observations: three unique paginated rows; hover, focus and press; variant baseline restoration; overlapping timeline tracks; once-only reveal; dismissible persistent overlays and session conditions; retained DOM identity; reduced-motion final styles; and isolated compiled interaction with hostile prop escaping and blocked parent, top, storage and network access.
